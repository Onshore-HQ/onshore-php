# Onshore SDK for PHP

The Onshore server SDK for PHP 8.1+ (curl and sodium extensions).

## Install

Not on Packagist yet. Add the repository to your `composer.json`, then require the package:

```json
"repositories": [{ "type": "vcs", "url": "https://github.com/Onshore-HQ/onshore-php" }]
```

```sh
composer require onshorehq/sdk:^0.1
```

## Documentation

Full reference, with every method, parameter, return value and error: https://docs.onshorevault.com/developers/sdks/php/
